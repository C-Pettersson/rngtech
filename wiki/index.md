# RNGTech Wiki

This is the player guide to RNGTech's machines. Each page covers how to craft a machine, what it does, its stages and Gear, and the recipes it runs. Crafting grids, recipe tables, and icons are generated from the mod's own data files, so they match the current build.

New to the mod? Start with [Getting Started](getting-started.md), then read the guides on [Stages](stages.md), [Rarity and Affixes](rarity-and-affixes.md), [Machine Mastery](machine-mastery.md), and [Gear](gear.md).
