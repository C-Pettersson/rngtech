# Rewards

Each job pays one kind of reward, shown on the chip, so you choose jobs by what they pay. The tier sets the base amount. Count ranges, conditions, Rush, and corruption add Bounty, which raises the amount.

| Reward | Tiers |
|---|---|
| <ItemLink id="rngtech:chaos_crystal" /> | All |
| <ItemLink id="rngtech:expansion_crystal" /> | All |
| <ItemLink id="rngtech:null_crystal" /> | All |
| <ItemLink id="rngtech:affix_modifier" /> | All |
| <ItemLink id="rngtech:mastery_refund" /> | All |
| <ItemLink id="rngtech:requisition" /> | All |
| A <ItemLink id="rngtech:glyph" /> of the job's tier | All |
| <ItemLink id="rngtech:volatile_catalyst" />, <ItemLink id="rngtech:affix_upgrade" />, or an <ItemLink id="rngtech:ascension_matrix" /> | III and higher |
| An unidentified [Unique](rngtech:uniques.md) | Prestige 2 or more |

Rewards never include FE, ores, ingots, or other materials. Tier V jobs are the only source of Tier V Glyphs for the [Phase Array](rngtech:phase-array.md).
