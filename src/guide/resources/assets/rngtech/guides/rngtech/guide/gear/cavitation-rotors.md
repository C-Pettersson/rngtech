# Cavitation Rotors

The rotor drives a [Cavitation Generator](rngtech:cavitation-generator.md). Its stage decides which recipes the generator can run, and it wears down as it works. A fully worn rotor is ejected as a Pitted Cavitation Rotor, which you can salvage in a Component Recycler.

| Cavitation Rotor | Stage | Notes |
|---|---:|---|
| <ItemLink id="rngtech:steel_cavitation_rotor" /> | 5 | |
| <ItemLink id="rngtech:titanium_cavitation_rotor" /> | 6 | |
| <ItemLink id="rngtech:nitrogen_extraction_rotor" /> | 6 | Low power. With a Nitrogen Separation Nozzle, makes Nitrogen from water. |
| <ItemLink id="rngtech:tungstensteel_cavitation_rotor" /> | 7 | |
| <ItemLink id="rngtech:aethergold_cavitation_rotor" /> | 7 | Burst rotor: much more generation and speed, but wears out quickly. |
| <ItemLink id="rngtech:nullite_cavitation_rotor" /> | 8 | |

**Used in:** [Cavitation Generator](rngtech:cavitation-generator.md) (required).
