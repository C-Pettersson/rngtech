# Automation

| Side | Behavior |
|---|---|
| Top | Inserts an Ammonia Catalyst Bed into the Gear slot. Accepts FE. |
| Bottom | Extracts Urea. |
| Sides | Accept FE. Extract Urea. |
| Any | Fills Nitrogen, Hydrogen, Carbon Exhaust, and Ammonia, and drains Ammonia. |

Nothing can insert into the Urea slot; you and automation can only take from it. The back cabinet has a port plate sized for a Universal Connector, the tidiest place to attach one. To throw gas away, use the purge buttons beside each tank, or right-click the machine with a **Purge Bucket** to void up to 1,000 mB. A normal right-click empties an input tank first, and sneaking empties the Ammonia tank first. Purging Nitrogen, Hydrogen, or Carbon Exhaust resets the cycle in progress.
