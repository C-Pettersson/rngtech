# Stability

Stability means something different on each machine:

| Machine | Effect of higher Stability |
|---|---|
| [Potential Reactor](rngtech:potential-reactor.md), [Corrosion Cell](rngtech:corrosion-cell.md) | More FE recovered per cycle. |
| [Cavitation Generator](rngtech:cavitation-generator.md) | Less wear on the installed rotor. |
| [Vacuum Collapse Generator](rngtech:vacuum-collapse-generator.md) | Meets recipe Stability minimums, and less instability slows each cycle less. |
| [Metal Press](rngtech:metal-press.md) | Less forming failure. |
| [Resonance Calibrator](rngtech:resonance-calibrator.md) | Higher stability floor on calibrated outputs. |
| [Solar Panel](rngtech:solar-panel.md) Array Controller | Recovers part of the weather penalty. |
| [Modular tools](rngtech:modular-tools.md) | Above 1.0, a per-block chance to skip both the durability and FE cost. 1.10 is a 10% chance. |
| [Battery Chassis](rngtech:battery-chassis.md) | Below 1.0, part of each [burst](rngtech:battery-chassis/burst.md) is lost. |
