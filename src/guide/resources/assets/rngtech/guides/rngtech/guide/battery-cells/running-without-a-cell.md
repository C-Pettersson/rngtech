# Running without a cell

The cell slot is optional on most processors, but leaving it empty has a cost. The machine keeps only its small internal buffer, and:

| Machine | Without a cell |
|---|---|
| [Crusher](rngtech:crusher.md) | Keeps only 75% of its Bonus Output above 1×. Crusher Battery Link affixes, and weakly the Scuffed Crush Head affix, win some of that back. The Cell Bypass keystone in [Machine Mastery](rngtech:machine-mastery.md) removes the penalty. |
| Electric [Furnace](rngtech:furnace.md) | 25% less Processing Speed. |
| [Alloy Furnace](rngtech:alloy-furnace.md) | 15% less Processing Speed and 10% reduced Stability. |
| [Metal Press](rngtech:metal-press.md) | 15% less Processing Speed and 20% reduced Stability. |
| [Resonance Calibrator](rngtech:resonance-calibrator.md) | 15% less Processing Speed and 10% reduced Calibration Quality. |
| [Melter](rngtech:melter.md) | 20% less Processing Speed. |
| [Component Assembler](rngtech:component-assembler.md) | 15% less Processing Speed. |

Your modpack can change the Crusher and Furnace penalties.
