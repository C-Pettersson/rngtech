# Mastery and Ascendancies

Each completed calibration earns Mastery XP; higher-stage recipes earn more. Multi-lane chassis earn XP for every job in a cycle. Calibrators start from the Control start of the shared [Machine Mastery](rngtech:machine-mastery.md) tree, which they share with the [Metal Press](rngtech:metal-press.md). They choose between the **Harmonist**, which rewards long runs of the same family with a rising stability floor, and the **Mass Tuner**, which makes multi-lane chassis cheaper to run. See [Resonance Calibrator ascendancies](rngtech:machine-mastery.md#ascendancies).

Extra components from Super Output earn no XP. Changing your Mastery allocation restarts the current calibration, but keeps your items and patterns.
