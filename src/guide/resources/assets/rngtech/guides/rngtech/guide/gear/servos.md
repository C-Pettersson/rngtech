# Servos

Servos add processing speed, stability, temperature stability, and overheat tolerance. Stage 6 and higher Servos also soften the strain from short power drops.

| Servo | Stage | Notes |
|---|---:|---|
| <ItemLink id="rngtech:steel_servo" /> | 4 | Needs no Lubricant to craft. |
| <ItemLink id="rngtech:titanium_servo" /> | 6 | |
| <ItemLink id="rngtech:tungstensteel_servo" /> | 7 | |
| <ItemLink id="rngtech:nullite_servo" /> | 7 | Sidegrade: half processing speed, but **Auto Purge** lets fluid machines void overflowing output fluid instead of stopping. |
| <ItemLink id="rngtech:exotic_servo" /> | 8 | |

Titanium and higher Servos need Lubricant and can also be made in the [Component Assembler](rngtech:component-assembler.md).

**Used in:**

| Machine | Slot |
|---|---|
| [Metal Press](rngtech:metal-press.md) | Required on the Metal Press, optional on the Crude Metal Press. Any stage. |
| [Alloy Furnace](rngtech:alloy-furnace.md) | Optional, up to the chassis stage. |
| [Melter](rngtech:melter.md) | Optional, any stage. |
| [Coal Gasifier](rngtech:coal-gasifier.md), [Syngas Combustor](rngtech:syngas-combustor.md), [Steam Methane Reformer](rngtech:steam-methane-reformer.md) | Optional, Stage 4 or higher. |
| [Compressor Tank](rngtech:compressor-tank.md) (Steel and higher) | Four slots, at least one required, up to the tank's stage. |
| [Cavitation Generator](rngtech:cavitation-generator.md) | Optional, Stage 6 or higher. |

- Requires the Bronze material to be enabled.
- Requires the Steel material to be enabled.
