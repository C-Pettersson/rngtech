# Void Chambers and Dimensional Stabilizers

The [Vacuum Collapse Generator](rngtech:vacuum-collapse-generator.md) needs both. The **Void Chamber**'s stage decides which recipes it can run and adds generation and stability. The **Dimensional Stabilizer** improves stability, efficiency, and residue handling.
