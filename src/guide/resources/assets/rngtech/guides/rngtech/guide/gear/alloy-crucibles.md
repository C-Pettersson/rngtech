# Alloy Crucibles

The crucible sets how many input slots an [Alloy Furnace](rngtech:alloy-furnace.md) has and adds mixing stability and speed.

| Alloy Crucible | Stage | Input slots |
|---|---:|---:|
| <ItemLink id="rngtech:bronze_alloy_crucible" /> | 3 | 3 |
| <ItemLink id="rngtech:steel_alloy_crucible" /> | 4 | 3 |
| <ItemLink id="rngtech:titanium_alloy_crucible" /> | 6 | 4 |

**Used in:** [Alloy Furnace](rngtech:alloy-furnace.md) (required, up to the chassis stage).

<RecipesFor id="rngtech:bronze_alloy_crucible" />

- Requires the Bronze material to be enabled.
