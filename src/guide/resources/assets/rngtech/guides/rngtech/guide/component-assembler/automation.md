# Automation

| Side | Behavior |
|---|---|
| Top | Inserts into the four item input slots. Each slot accepts only what a recipe matching the other filled slots needs in that position. An item a recipe needs in two positions fills both evenly; see [Automation](rngtech:automation.md). |
| Bottom | Extracts finished items from the output rack. Ingredient leftovers are pushed into the inventory below; see [Automation](rngtech:automation/ingredient-leftovers.md). |
| Sides | Insert dry electrolyte or filled fluid containers into the fluid slot, and extract empty containers. |
| Any | Accepts FE and assembly fluids, for example from a [Universal Cable](rngtech:universal-cable.md). |

Gear slots are not reachable by automation.
