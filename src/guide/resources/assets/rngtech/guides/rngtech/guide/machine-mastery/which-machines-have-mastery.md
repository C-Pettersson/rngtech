# Which machines have Mastery

Seven machine families have a **Mastery** tab:

| Family | Machines | Starting point on the tree |
|---|---|---|
| Crusher | Every [Crusher](rngtech:crusher.md) chassis | Drive |
| Furnace | Every [Furnace](rngtech:furnace.md), including the Stage 0 fuel Furnace | Drive / Reserve |
| Alloy Furnace | Every [Alloy Furnace](rngtech:alloy-furnace.md) chassis | Drive / Reserve |
| Metal Press | Crude Metal Press and Metal Press ([Metal Press](rngtech:metal-press.md)) | Control |
| Resonance Calibrator | Every [Resonance Calibrator](rngtech:resonance-calibrator.md) chassis | Control |
| Melter | [Melter](rngtech:melter.md) | Reserve / Control |
| Forestry Companion | The Forestry Companion cart ([Forestry Cart Station](rngtech:forestry-cart-station.md)) | Control / Drive |

Other machines, Gear, and cables do not level up.

[Work Orders](rngtech:work-orders.md) give every processing machine repeatable jobs, with or without Mastery, so a maxed machine still has goals. Jobs give no XP or tree points. Chips stay with the machine, not its Mastery, so a Soul Transfer does not move them.
