# RNGTech Guide

RNGTech treats machines like RPG characters: every machine, Gear part, and Battery Cell rolls its own rarity and affixes. Start with Getting Started, then look up a machine when you build it.

Hover an item and hold the guide key to open its page. Recipe lists are in JEI.
