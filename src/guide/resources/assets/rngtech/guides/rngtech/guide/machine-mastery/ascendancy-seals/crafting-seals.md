# Crafting Seals

Seals are crafted at a crafting table. Seal I needs a calibrated conductive component from the [Resonance Calibrator](rngtech:resonance-calibrator.md); the Notes column shows the stage and stability it must have.

- **Calibrated Conductive Component** must be a Conductive calibration, Stage 5+, stability 70+.
- Requires the Sparksteel material to be enabled.
- Requires the Aluminum material to be enabled.
- **Calibrated Conductive Component** must be a Conductive calibration, Stage 5+, stability 55+.
- **Calibrated Diamond Crystal** must be a Logic calibration, Stage 6+, stability 85+.
- Requires the Tungstensteel material to be enabled.
- Requires the Nullite material to be enabled.
- **Calibrated Diamond Crystal** must be a Logic calibration, Stage 6+, stability 95+.
- Requires the Naquadah material to be enabled.

The Seal Cores at the center of each recipe come from the [Component Assembler](rngtech:component-assembler.md): the <ItemLink id="rngtech:primed_seal_core" /> uses Electrolyte Solution and the <ItemLink id="rngtech:lubricated_seal_core" /> uses Lubricant.
