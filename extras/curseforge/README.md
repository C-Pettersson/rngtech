# CurseForge Project Page

This folder holds the copy for the [RNGTech CurseForge page](https://www.curseforge.com/minecraft/mc-mods/rngtech). Edit it here first, then paste it into the CurseForge project settings, so the page and the repository stay in sync.

## Summary

The short summary shown in CurseForge search results:

```text
Machines that drop like loot: rarity, affixes, and a passive tree for your factory.
```

## Description

[description.md](description.md) describes `main`, which may be ahead of the latest CurseForge file. Paste it into the description editor in Markdown mode when you publish the release it describes, not before. While 2.0 is in alpha, keep the alpha note near the top; remove it, and the matching README note, when 2.0 becomes a release file. Its images are the project's gallery attachments on `media.forgecdn.net`. Upload a new image to the gallery first, then use its attachment URL.

Every link must be an absolute URL; relative repository links do not work on CurseForge. Describe only shipped features, and link to the player wiki for details.
