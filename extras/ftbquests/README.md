# RNGTech FTB Quests

This folder contains optional FTB Quests content for pack creators. It is not
part of RNGTech's standalone runtime config.

To include these quests in a modpack, copy `config/ftbquests` from this folder
into the pack instance root so it lands at `config/ftbquests`.

Quest rewards are left as authored for pack creators to review, tune, or keep
for their pack progression.
